# q4
> openlab初试第四题
>选择方向2
>这是一个桌面宠物程序，支持聊天互动，语音播报，自定义图片，快速截图等功能，使用方法如下：
## 一、运行前准备
### 1. 环境依赖
bash
pip install PyQt5 pyttsx3
pip install pynput          # 可选：启用全局热键（F9/F10 任何窗口下都有效）
Linux 语音引擎：sudo apt install espeak-ng libespeak1

### 2. 配置 DeepSeek API Key（必须，否则无法聊天）
平台	命令
Windows PowerShell	$env:DEEPSEEK_API_KEY = "sk-xxxx"
Linux / macOS	export DEEPSEEK_API_KEY="sk-xxxx"
### 3. 启动程序
bash
python desktop_pet.py
⚠️ 若提示 No module named 'PyQt5'，检查是否用错了 Python 版本（参考 python -c "import sys; print(sys.executable)"）。
若确实如此，使用`C:\Users\用户名\Desktop\.venv-pyqt5\Scripts\python.exe
                C:\Users\用户名\Desktop\pet.py`

## 二、基础操作
操作	效果
左键按住拖动	移动宠物到桌面任意位置（拖拽不会误触发点击）
左键单击	宠物跳跃 + 随机说一句话（气泡显示，不朗读）
左键双击	打开对话窗口，与 DeepSeek 聊天
右键单击	弹出功能菜单
## 三、快捷键
快捷键	功能	说明
F9	切换配色	红→橙→黄→绿→蓝→靛→紫 循环，不影响已加载的图片/GIF
F10	全屏截图	自动复制到剪贴板，气泡显示截图尺寸
Esc	关闭对话窗口	仅在聊天框打开时有效
F9/F10 优先走 pynput 全局监听（需安装 pynput），未安装时需先点击宠物让窗口获得焦点。两路触发已做 200ms 去重。

## 四、右键菜单功能
菜单项	功能
💬 和我聊天（也可双击）	打开对话窗口
🔇 静音 / 🔊 开启语音朗读	切换 pyttsx3 语音开关
🚶 暂停 / 开启自动走动	控制宠物是否在桌面散步
📷 截图到剪贴板（F10）	菜单入口的截图（等价 F10）
🎨 换个颜色（F9）	菜单入口的换色（等价 F9）
🖼 更换宠物图片…	选择本地 gif/webp/png/jpg 作为新形象
🔄 恢复默认形象	清除图片，回到默认绘制的小蓝
❌ 退出	保存状态并退出程序
## 五、对话功能（DeepSeek API）
双击宠物 或 右键 → 和我聊天 打开对话框。

输入问题，按 回车 或点 发送。

回复会：

显示在对话框（带历史记录）

显示在宠物头顶气泡

由 pyttsx3 朗读（若语音开启）

上下文：保留 system prompt + 最近 10 条消息，防止 token 无限增长。

错误处理：无 Key / 网络错误 / HTTP 错误都会以友好提示显示在对话框，不会崩溃。

## 六、语音朗读
使用 pyttsx3（离线），在独立 daemon 线程中运行，绝不阻塞 UI。

自动挑选中文音色（huihui / zh / chinese）。

朗读前自动过滤 emoji 等不可发音字符。

可通过右键菜单或状态记忆随时静音。

若系统未安装 pyttsx3 或语音引擎，自动降级为纯文字，不报错。

## 七、自动走动
宠物在屏幕左右边界之间缓慢移动，速度 1.0 px/帧。

碰到屏幕边缘自动反弹并翻转方向。

在 walk（行走） 与 idle（待机） 状态之间随机切换。

行走时有上下浮动 + 左右翻转 + 影子动画。

拖拽时、对话窗口打开时自动暂停走动。

## 八、视觉细节（默认形象）
透明无边框、始终置顶、不占任务栏。

眼睛跟随鼠标移动（已修复镜像反转问题）。

随机眨眼动画。

尾巴摇摆、身体呼吸浮动。

单击时跳跃动画。

腮红、高光等小细节。

## 九、状态记忆
保存文件：~/.desktop_pet_state.json

记录内容	保存时机	恢复时机
宠物位置 (x, y)	拖拽结束、退出	启动时（若超出屏幕会自动纠正）
语音开关	切换语音、退出	启动时
自动走动开关	切换走动、退出	启动时
配色索引	换色、退出	启动时
宠物图片路径	换图、恢复默认、退出	启动时（文件不存在则回退默认形象）

## 十一、自定义宠物形象
在程序目录下创建 assets/ 文件夹。

放入以下任一文件（按优先级）：

text
assets/pet.gif     ← GIF 动画优先
assets/pet.webp
assets/pet.png
assets/pet.jpg
assets/pet.jpeg
启动时自动加载；也可右键菜单 🖼 更换宠物图片… 手动选择任意路径的图片。

💡 图片/GIF 形象不受 F9 换色影响，只有默认绘制的小蓝会变色。

## 十二、常见问题速查
现象	解决方法
No module named 'PyQt5'	用 python -m pip install PyQt5，确认 Python 版本一致
聊天没反应 / 提示未检测到 Key	检查 DEEPSEEK_API_KEY 环境变量，重启程序使其生效
没有声音	确认系统语音引擎已安装；右键菜单检查语音是否被静音
F9/F10 无效	安装 pynput 或先点击宠物让窗口获得焦点
眼睛朝反方向看	已修复（eye_dx * direction 补偿镜像）
图片加载不了	确认格式为 gif/webp/png/jpg/jpeg/bmp
位置跑到屏幕外	启动时会自动纠正到可见区域
想彻底重置	删除 ~/.desktop_pet_state.json
